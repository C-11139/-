# 👁️ AI-Shopping-Copilot (桌面伴随型 AI 购物助手)

基于多模态大模型（Vision Agent）与桌面悬浮窗技术开发的实时网购决策助手。按下 `F8` 即可实现“无感截屏 -> 识图提取SKU -> 全网比价 -> 避坑决策”的闭环体验。

## 💡 产品背景与痛点
- **跨平台比价繁琐**：传统比价需频繁切屏、复制粘贴，打断心流。
- **信息孤岛与套路**：平台自带比价仅为“站内防守工具”，且充斥着虚假好评与复杂的满减套路。
- **全屏捕捉的隐私边界**：需要在不窥探用户全屏隐私的前提下，精准分析商品。

## ✨ 核心功能
- **⚡ 全局伴随，无感触发**：无边框透明 UI 悬浮于桌面，监听全局快捷键 `F8`，隐藏自身后截屏分析。
- **👁️ 视觉感知与意图提取**：调用 `qwen-vl-plus` 视觉大模型，精准识别屏幕截图中的品牌与具体型号。
- **🔍 全网实时比价与避坑**：结合 DuckDuckGo 联网搜索，由大模型输出结构化的【底价预估】与【差评预警】决策报告。
- **🛡️ 防幻觉工作流**：采用 `识图提取 -> 联网检索 -> LLM总结` 的三步 Agent 架构，强制约束模型基于真实搜索结果作答。

## 🛠️ 技术栈
- **UI 框架**：PyQt5 (无边框悬浮窗、多线程防卡死)
- **AI 能力**：阿里云百炼平台 (Qwen-VL 多模态大模型)
- **工具链**：DuckDuckGo Search (时效性检索)、PyAutoGUI (屏幕捕捉)
